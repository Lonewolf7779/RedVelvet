# @red-velvet/ui

Design system foundation and architectural tokens for **Project Red Velvet**.

## Visual Direction

- **Color Palette**: Deep burgundy (`#4A0E17`), wine red (`#721B29`), pure white (`#FFFFFF`), charcoal (`#1C1C1E`), concrete grey (`#D1D1D6`), and deep noir (`#0A0A0A`).
- **Typography**: Elegant thin serif for headlines (`Cormorant Garamond`), crisp architectural sans for body (`Inter`), and monospace for system readouts (`JetBrains Mono`).
- **Composition**: High-fashion editorial magazine aesthetics, hairline dividers, disciplined grid spacing, zero cartoonish cards or purple gradients.
